# 三筆三様 — 編集用プロジェクト

公開バージョン9の編集元ソース一式です。Webページを取得して保存したものではなく、Siteのソースリポジトリから書き出しています。

## 起動

Node.js 20以上を用意し、このフォルダーで以下を実行します。

```sh
npm run dev
```

ブラウザーで http://127.0.0.1:3000 を開きます。終了は Ctrl+C です。
依存パッケージはありません。npm install は不要です。環境の運用上必要なら npm ci も実行できます。

```sh
npm run check
npm run build
```

このアプリは静的構成のため、buildはソースと参照ファイルの検査を行います。コンパイルやバンドルは不要で、distをそのまま公開します。
別ポートは `npm run dev -- --port 3001` で指定できます。

## 編集するファイル

- `dist/index.html` — HTMLの入口と初期画面
- `dist/app.js` — 全画面の描画、状態管理、手書き入力、画像取込、画面遷移、結果、記録、設定
- `dist/style.css` — 全画面のスタイル、レスポンシブ対応、焦点ぼかし、アニメーション
- `dist/assets/intro.mp4` — 元プロジェクトに含まれる動画（現在の画面では未使用）
- `scripts/serve.mjs` — 今回追加した開発用静的サーバー
- `scripts/check.mjs` — 今回追加した検査処理
- `package.json` / `package-lock.json` — 起動・検査の設定と依存関係
- `.openai/hosting.json` — 別Siteとして登録するための静的公開設定

distという名前ですが、ここにあるHTML・JavaScript・CSSが編集元そのものです。React・TypeScript・ビルド前の別ソースは元プロジェクトに存在しません。JavaScriptは圧縮されておらず直接編集できます。コード内のSVGアイコンやファビコンも含まれています。編集後にブラウザーを再読み込みすると反映されます。

## 別のChatGPTアカウントのWorkで再構築

1. 別アカウントのWorkにこのZIPを添付します。
2. `WORK_IMPORT.md` の依頼文を送ります。
3. 新しいSiteを登録して公開します。公開URLは新しく発行されます。

元Siteのproject_idは移行用設定から除外しています。元のIDを貼り戻さないでください。元Siteのアクセス権・アカウント・URLを移管するZIPではありません。公開元への変更は加えていません。

## 外部サービスとデータ

- Google FontsのShippori MinchoとNoto Sans JPをCSSから読み込みます。初回に同じ書体を表示するにはインターネット接続が必要です。オフラインではOSの日本語フォントに切り替わります。フォントファイルは元プロジェクトにはありません。
- 診断結果と行動特徴は固定のサンプルです。筆跡を自動解析するバックエンドはありません。
- 手書き・取り込んだ画像・履歴はページを開いている間のメモリーに保持されます。再読み込みで消去され、ZIPにも含まれません。
- プロフィールと表示設定はブラウザーのlocalStorageに保存されます。別の環境やURLには引き継がれません。
- APIキー、サーバー環境変数、データベース、認証サーバーは不要です。
- 起動用サーバーは開発専用です。公開時には静的ホスティングを使います。
